# Hustel - Web Directory Management Platform

Hustel is a comprehensive web directory platform designed to showcase businesses and services. It features a clean, modern interface with admin capabilities for content management.

## Project Overview

- **Repository**: Hustel web directory platform
- **Status**: Development completed with admin interface
- **Type**: Business directory platform
- **Location**: `web-experiments/hustel/`
